RESEARCH MOTIVATION

The Metabolic Cascade

Metabolic, vascular and renal dysfunction can coexist. BioCascade explores these relationships using NHANES 2017–2018 data and a research-defined proxy inspired by HFpEF (heart failure with preserved ejection fraction). The target is not a confirmed HFpEF diagnosis.

The proxy flags two or more threshold-defined abnormalities across blood pressure, HbA1c and serum creatinine. The models compare direct and indirect predictors of that proxy.

What the results mean

Target overlap: Model A is an upper-bound benchmark, not proof of independent screening.
Independent signal: Model B ranks proxy cases using indirect features, but misses some and produces false positives.
Limitations: Cross-sectional data, proxy outcome and no external clinical validation. Scores are not calibrated disease probabilities.

ARCHITECTURE

The Interpretability Engine

End-to-end pipeline from raw data to explainable predictions

Data Pipeline

NHANES 2017-2018 (5,533 participants) → DuckDB storage → Feature engineering → Label definition (multi-system dysfunction proxy)

ML Training

Random Forest with class balancing → Two-model validation → Feature importance ranking → Cross-validation → Model persistence (joblib)

SHAP Explanations

TreeExplainer for global importance → Waterfall plots for individual patients → Feature contribution analysis → Model score interpretation

Technology Stack

Python 3.13 DuckDB scikit-learn SHAP NumPy / Pandas Flask HTML/CSS/JS Git
